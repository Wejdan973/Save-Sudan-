
Save Sudan 🛡️

Problem Statement  
The project addresses the critical need to identify safe and dangerous areas across Sudan, in order to support internally displaced people (IDPs) and returnees. It also facilitates the delivery of humanitarian and medical aid to affected regions.

How the Solution Works  
The solution is a simple, interactive web page displaying a live map of Sudan.  
It visually highlights:
- ✅ *Safe zones* in green  
- ❌ *Dangerous zones* in red  

The map is updated every *3 seconds*, and the interface is designed to be intuitive and easy to use.

Technologies Used  
- *AI Tools*: Claude  
- *Languages*: HTML, CSS, JavaScript  

Features  
- Clean and simple user interface  
- Real-time data updates  
- Easily extendable and modifiable  

Expected Impact on Sudanese Society  
- Help save lives by guiding displaced individuals and returnees toward safer routes  
- Support aid organizations in locating and reaching vulnerable areas faster  
- Reduce the security information gap across communities
